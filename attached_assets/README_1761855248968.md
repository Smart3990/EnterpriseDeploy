# DevIgnite AI – Enterprise-Ready Project with Auto-Deploy Workflows

## 🚀 Overview
DevIgnite AI is an all-in-one AI development, automation, and marketing suite designed for enterprises, fully deployable on Replit, GitHub, Netlify, and Vercel.

### Highlights
- Lovable-inspired UI (React + Tailwind + Framer Motion)
- AI content generation (text, image, voice, video)
- n8n workflow automation (800+ templates)
- Supabase + PlanetScale for database
- Auto-deploy via GitHub Actions
- Zero-cost multi-AI fallback system

### How to Run on Replit
1. Upload this ZIP to Replit (Node.js + Next.js environment).
2. Run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the web preview and explore.

### Deployment
- Push to GitHub → automatic deploy to Netlify/Vercel.
- Apply `migrations/enterprise_schema.sql` to Supabase.
